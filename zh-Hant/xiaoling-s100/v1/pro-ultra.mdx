> **開發者預覽版／硬體尚未驗證：** S100 的 ROS 整合與實體行為尚未在目標裝置驗證。本機測試及產品設定檔標籤不能證明硬體相容性。

Warmcore 產品規格將視覺與追蹤列為 Pro 功能；Ultra 包含這些功能，並增加臉部觸摸。產品描述不能用來辨識主板，也不能證明特定機器的介面存在。

| 功能 | 產品規格 | SDK 預覽版與證據 |
| --- | --- | --- |
| 視覺與追蹤 | Pro 與 Ultra | 已實作影像與跟隨狀態訂閱；實際相機與追蹤功能仍需在目標硬體驗證。 |
| 臉部觸摸 | Ultra 新增 | 已實作離線正規化；已檢查的基準中，尚未確認即時事件路徑。 |
| RF433 | 依個別裝置而定 | 已實作接收器訂閱；裝置是否存在及代碼對應仍需驗證。 |

請與獲授權的操作人員確認 SKU、主板、韌體與周邊設備。SDK Profile 只是標籤，不代表硬體辨識結果。
