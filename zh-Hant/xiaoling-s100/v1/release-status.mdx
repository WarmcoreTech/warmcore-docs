> **開發者預覽版／硬體尚未驗證：** S100 的 ROS 整合與實體行為尚未在目標裝置驗證。本機測試及產品設定檔標籤不能證明硬體相容性。

已合併的私人 SDK 參考版本為 `0.1.0a1`，屬開發者預覽版。它已實作部分 ROS、WebSocket 與離線介面；實際可用性取決於部署環境。

| 證據 | 參考 SDK 提交的狀態 |
| --- | --- |
| SDK 實作 | 部分介面已實作；手動頭部、眼球及嘴部動作停用。 |
| 離線測試 | 已記錄單元測試及部分 HTTP／WebSocket 迴環測試。 |
| 目標 ROS 執行環境 | 尚未在 S100 裝置基準上測試。 |
| 硬體 | 尚未驗證；各功能都需要個別驗收。 |
