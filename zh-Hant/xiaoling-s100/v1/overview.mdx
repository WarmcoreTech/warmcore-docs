> **開發者預覽版／硬體尚未驗證：** S100 的 ROS 整合與實體行為尚未在目標裝置驗證。本機測試及產品設定檔標籤不能證明硬體相容性。

Xiaoling S100 SDK 是獨立的 ROS 2 與 Python 開發者預覽版。安裝套件 `xiaoling-s100-sdk` 的版本為 `0.1.0a1`，Python 匯入名稱為 `xiaoling_s100`。技術參考基準是 RDK S100 與 ROS 2 Humble；請逐台確認實際主板與軟體。Pro 或 Ultra 的產品名稱不能證明其主板型號。

預覽版已實作部分對話、音訊、觀察、觸摸、RF433、視覺與文字模型介面。離線測試涵蓋部分路徑，但目標 ROS 與硬體驗收仍待完成。手動頭部、眼球及嘴部動作已停用。詳見[功能差異](/zh-Hant/xiaoling-s100/v1/pro-ultra)與[發布狀態](/zh-Hant/xiaoling-s100/v1/release-status)。
