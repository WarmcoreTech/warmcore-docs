探索 Warmcore Tech 兩套互相獨立的 SDK 開發者預覽版。每套 SDK 都有自己的 Python 套件、目標執行環境及技術文件。

## Xiaoling X3 SDK

適用於 **Xiaoling Robot** 與 **RDK X3 Head 2.0 V1.0.2**。套件名稱：`warmcore-xiaoling-sdk`；匯入名稱：`warmcore_xiaoling`。從 [X3 總覽](/zh-Hant/xiaoling-x3/v1/overview) 開始。

## Xiaoling S100 SDK

以 RDK S100 與 ROS 2 Humble 為技術參考基準的獨立預覽版。套件名稱：`xiaoling-s100-sdk`；匯入名稱：`xiaoling_s100`。請逐台確認實際主板，再閱讀 [S100 總覽](/zh-Hant/xiaoling-s100/v1/overview)。

> **開發者預覽版／硬體尚未驗證：** 兩套 SDK 都具有離線測試證據，但目標機器人執行環境與硬體驗收仍未完成。

網址中的 `v1` 代表文件版本代別，不表示 SDK 已推出穩定版 1.0。
