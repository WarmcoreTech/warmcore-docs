## 唯讀驗收檢查

請在已授權的 SDK 目錄，使用操作人員確認的 Namespace：

```bash
python3 examples/x3_acceptance.py --ros --namespace robot --wait 5
```

若有核准的 WebSocket 端點，先安裝選用的用戶端相依套件，再執行：

```bash
python examples/x3_acceptance.py --websocket ws://ROBOT_HOST:9090 --wait 30
```

將 `ROBOT_HOST` 替換為操作人員提供的端點。WebSocket 報告只統計觀察到的事件，不保存事件文字。裝置閒置時，在觀察期間可能完全沒有事件；缺少事件本身不代表機器人故障。絕對不要將端點暴露至公用網際網路。
