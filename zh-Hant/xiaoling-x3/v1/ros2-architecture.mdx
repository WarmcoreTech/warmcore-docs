## 整合方式

Python 應用程式可在相容的 ROS 環境中使用 SDK 的 ROS 用戶端，也可透過操作人員核准的 rosbridge 部署，使用唯讀 WebSocket 用戶端監聽對話事件。這是不同的整合路徑；WebSocket 觀察功能不提供機器人指令存取權限。

## 探索與證據

ROS 名稱可能受到 Namespace 或 Remapping 影響。SDK 診斷會檢查觀察到的名稱、型別與部分 QoS 路由。節點圖結果只是一次快照，不能證明端點身分、授權、持續健康狀態、訊息送達或實體行為。預覽版介面規約詳見 [Topic 與 Service](/zh-Hant/xiaoling-x3/v1/topics-services)。

## 網路邊界

請使用操作人員管理的網路存取控制。用戶端的 Topic 白名單只能限制該用戶端，無法保護 rosbridge 伺服器不受其他用戶端存取。絕對不要直接將橋接服務暴露至公用網際網路。不受信任的連線應使用操作人員管理、具備憑證驗證與存取控制的 TLS 端點。
