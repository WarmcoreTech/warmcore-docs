## 文字模型整合

預覽版適配器透過 `LLM_CHAT_ENDPOINT` 接受相容的 Chat Completions 端點，並透過 `LLM_MODEL` 指定模型；只有必要時才設定 `LLM_API_KEY`。機密資訊應存放於環境變數或核准的密鑰管理系統，不要寫入原始碼或共用日誌。除 Loopback 外，金鑰必須經 HTTPS 傳輸。純 HTTP 也會暴露對話文字，只能在 Loopback 或明確核准的受保護網路使用。

在已授權的 SDK 目錄執行以下指令，可在工作站取得文字回應：

```bash
python3 examples/llm_robot_reply.py "Hello"
```

這需要設定相容的模型提供者。線上提供者的相容性仍未驗證。將輸出傳送給機器人可能引發音訊播放，須另取得操作人員核准。

## 音訊功能範圍

預覽版提供實驗性 PCM 工具，但播放功能需要相容且獲授權的介面套件，以及實際裝置驗證。預覽版不會取代完整的麥克風至模型語音管線，也不保證嘴型同步。請妥善保護錄音與對話內容。
