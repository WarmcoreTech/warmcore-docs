> **開発者向けプレビュー／ハードウェア未検証：** X3 ハードウェアおよび実機に展開されたロボットの実行環境は未検証です。ローカルテストだけでは、機器の互換性、物理的な動作、安全な運用を確認できません。

## 開始前の準備

利用を許可された SDK のチェックアウトを取得し、バージョンを確認してください。運用担当者が承認したワークステーションと分離ネットワークを用意します。ROS の探索には、対応する ROS 環境、ドメイン、ミドルウェア、名前空間を担当者に確認してください。ロボットのソフトウェアは変更しないでください。

## ROS グラフを観察する

ワークステーションでロボットに対応した ROS 環境を読み込み、[インストール](/jp/xiaoling-x3/v1/installation)の手順で SDK を導入したうえで、許可されたチェックアウトから次を実行します。

```bash
python3 examples/x3_acceptance.py --ros --namespace robot --wait 5
```

`robot` は担当者が確認した名前空間に置き換えます。ルート名前空間を使用する場合は `--namespace` を省略します。レポートには検出したインターフェースが記録されますが、探索だけではメッセージの到達や機器の安全性は保証されません。

## 結果の解釈

終了コード `0` は選択した観測が基準を満たしたこと、`1` は探索不足または既知の対話経路の不一致、`2` は入力・通信・セットアップのエラーを表します。SDK のバージョンと観測環境を添えて、機密情報を除いたレポートを保存してください。[トラブルシューティング](/jp/xiaoling-x3/v1/troubleshooting)も参照してください。
