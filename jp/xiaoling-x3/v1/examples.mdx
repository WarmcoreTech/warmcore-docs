## 読み取り専用の受け入れ確認

許可された SDK チェックアウトで、担当者が確認した名前空間を指定します。

```bash
python3 examples/x3_acceptance.py --ros --namespace robot --wait 5
```

承認された WebSocket エンドポイントでは、オプションのクライアント依存関係を導入してから実行します。

```bash
python examples/x3_acceptance.py --websocket ws://ROBOT_HOST:9090 --wait 30
```

`ROBOT_HOST` は担当者から提供されたエンドポイントに置き換えます。WebSocket のレポートは観測したイベント数のみを記録し、本文は保存しません。ロボットが待機中なら観測期間にイベントがなくても正常な場合があります。イベントがないことだけで故障とは判断できません。エンドポイントをインターネットに公開しないでください。

## ワークステーションのみでのテキスト処理

テキストプロバイダーの例は[音声と LLM の連携](/jp/xiaoling-x3/v1/audio-llm)を参照してください。ローカル応答が得られてもロボットとの統合を証明しません。
