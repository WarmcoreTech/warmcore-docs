## オフライン準備と観測

`MouthController.prepare(ratio)` は `0` から `1` までの有限な正規化比率を検証し、データをオフラインで準備します。`HeadController.prepare_rpy(roll, pitch, yaw)` はラジアン単位の有限数値入力を検証し、データをオフラインで準備します。これらの検証は機械的な可動範囲や安全な姿勢を示すものではありません。

各コントローラーの `inspect(node)` は呼び出し元が所有する ROS ノードでグラフを調査するもので、動作指令は送りません。`EyeController.inspect(node)` が示すのは候補となるグラフ情報であり、眼球位置ではありません。

## 物理制御

口と頭部への手動書き込みは `MotionUnavailableError` を送出します。眼球には手動操作用 SDK API がありません。将来、物理制御を有効にするには、機器固有の制限、制御権の調停、停止動作、監督下での実機受け入れ検証が必要です。競合ノードが見つからないことを安全性の根拠にしないでください。
