> **開発者向けプレビュー／ハードウェア未検証：** X3 ハードウェアおよび実機に展開されたロボットの実行環境は未検証です。ローカルテストだけでは、機器の互換性、物理的な動作、安全な運用を確認できません。

## 稼働中のグラフを調査する

ワークステーション上でロボットに対応する ROS 環境を使用し、実際のデプロイ先を調べます。

```bash
ros2 node list
ros2 topic list -t
ros2 service list -t
```

SDK とソフトウェアのバージョン、名前空間、機密情報を除いた観測結果を記録してください。使用可能なノードやパッケージは、導入されたイメージと設定によって異なります。ノードがグラフに存在しても、正常動作や安全な制御は保証されません。

SDK の Python インポート名は `warmcore_xiaoling` です。ROS モジュールは互換性のある ROS 環境から提供されます。ベンダーのインターフェース定義は別途管理されており、このドキュメントでは再配布しません。期待するインターフェースが見つからない場合は、[トラブルシューティング](/jp/xiaoling-x3/v1/troubleshooting)を参照してください。
