> **開発者向けプレビュー／ハードウェア未検証：** X3 ハードウェアおよび実機に展開されたロボットの実行環境は未検証です。ローカルテストだけでは、機器の互換性、物理的な動作、安全な運用を確認できません。

## Python が `rclpy` をインポートできない

同じシェルで対応する ROS 環境を読み込み、SDK が ROS と同じ Python インタープリターで動作しているか確認してください。[インストール](/jp/xiaoling-x3/v1/installation)のインポート確認を再実行します。

## 必要なインターフェースが見つからない

担当者が承認したネットワーク、ROS ドメイン、ミドルウェア、名前空間、稼働ソフトウェアのバージョンを確認します。[ノードとパッケージ](/jp/xiaoling-x3/v1/nodes-packages)の読み取り専用コマンドでノードと名前を調査してください。探索だけでは配信や QoS の互換性を保証しません。

## WebSocket イベントが届かない

許可されたエンドポイント、ブリッジの稼働状況、アクセス方針、名前空間を確認してください。アイドル状態のロボットでは、観測中にイベントがない場合があります。共有ログに対話本文を出力しないでください。

## サポートを受ける

SDK とソフトウェアのバージョン、実行操作、終了コード、機密情報を除いたエラーメッセージを既存の Warmcore Tech サポート窓口に伝えてください。資格情報、アドレス、識別子、個人情報、対話本文、設定ダンプは除外してください。
