> **開発者向けプレビュー／ハードウェア未検証：** S100 の ROS 統合と実機動作は対象機器で検証されていません。ローカルテストやプロファイル名だけでは、ハードウェアの互換性を確認できません。

利用できるインターフェースはインストールされたイメージ、起動時の選択、接続された周辺機器によって変わります。担当者に互換 ROS 環境を確認し、実際のグラフを調べてください。

```bash
ros2 node list
ros2 topic list -t
ros2 service list -t
```

SDK のインポート名は `xiaoling_s100` です。ROS パッケージとベンダーの型サポートは許可された環境から提供されます。見つかった名前と型を対象の設定と比較してください。実行ファイルやパッケージ、グラフの項目があることだけでは、機器の動作やハードウェアの有効化は確認できません。
