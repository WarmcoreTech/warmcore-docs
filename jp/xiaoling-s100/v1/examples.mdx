## 模擬的な顔面タッチトークンを正規化する

このサンプルは ROS や実機にはアクセスしません。

```python
from xiaoling_s100 import Profile
from xiaoling_s100.events import FaceTouchAdapter

adapter = FaceTouchAdapter({"sample": "example"}, Profile.XIAOLING_ULTRA)
event = adapter.normalize("sample")
print(event.area, event.verified)
```

このマッピングは例示用であり、実際のタッチ位置を検証したものではありません。Fixture を使った完全なデモは、許可された SDK チェックアウトから `python examples/offline_touch.py` を実行してください。
