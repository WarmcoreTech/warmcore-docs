title: "インストール"
description: "S100 SDK の Python および ROS 環境を準備する"
---

> **開発者向けプレビュー／ハードウェア未検証：** S100 の ROS 統合と実機動作は対象機器で検証されていません。ローカルテストやプロファイル名だけでは、ハードウェアの互換性を確認できません。

Python 3.10 以降と許可された SDK チェックアウトを使用してください。チェックアウトからベース SDK をインストールします。

```bash
python -m pip install .
python -c "import xiaoling_s100; print('SDK import OK')"
```

インポート成功はローカルのパッケージ利用可否のみを示します。ROS 連携では、デプロイ環境に適合する Python インタープリターと ROS 環境を使用してください。一部機能には適切な権限とバージョンが一致するベンダーメッセージ型のサポートが必要です。承認済みの方法で入手してください。このサイトからは配布しません。ロボットの Overlay を上書きしないでください。

オプションの WebSocket クライアント用に `python -m pip install ".[rosbridge]"` を実行すると、依存パッケージがダウンロードされることがあります。組織のパッケージポリシーと担当者が承認したネットワークを使用してください。
