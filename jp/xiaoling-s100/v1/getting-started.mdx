> **開発者向けプレビュー／ハードウェア未検証：** S100 の ROS 統合と実機動作は対象機器で検証されていません。ローカルテストやプロファイル名だけでは、ハードウェアの互換性を確認できません。

利用を許可された SDK チェックアウトと配布条件を入手し、Python 3.10 の環境を用意して[インストール](/jp/xiaoling-s100/v1/installation)に従ってください。チェックアウト内でオフライン Fixture サンプルを実行します。

```bash
python examples/offline_touch.py
```

この処理は模擬イベントのみを扱い、ROS、ネットワーク、機器 I/O にはアクセスしません。受信機や顔面タッチハードウェアの検証にはなりません。許可された ROS 環境では、担当者が確認したグラフ検査を実行できます。

```bash
python examples/monitor.py --namespace robot --inspect-only
```

`robot` をデプロイ先の名前空間に置き換えるか、ルート名前空間ならオプションを省略します。探索結果は一時点のスナップショットであり、機器動作の証明ではありません。
