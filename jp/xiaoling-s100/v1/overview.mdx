> **開発者向けプレビュー／ハードウェア未検証：** S100 の ROS 統合と実機動作は対象機器で検証されていません。ローカルテストやプロファイル名だけでは、ハードウェアの互換性を確認できません。

Xiaoling S100 SDK は独立した ROS 2・Python 開発者向けプレビューです。配布パッケージ `xiaoling-s100-sdk` のバージョンは `0.1.0a1`、インポート名は `xiaoling_s100` です。RDK S100 と ROS 2 Humble を技術上の基準としますが、実際に搭載されたボードとソフトウェアは機器ごとに確認してください。Pro や Ultra という製品名だけではボード型番を特定できません。

プレビューには対話、音声、監視、タッチ、RF433、ビジョン、テキストモデルの一部インターフェースが実装されています。一部はオフラインでテストされていますが、対象 ROS とハードウェアの受け入れ検証は未完了です。頭部・眼球・口の手動動作は無効です。[機能の違い](/jp/xiaoling-s100/v1/pro-ultra)と[リリース状況](/jp/xiaoling-s100/v1/release-status)を参照してください。
