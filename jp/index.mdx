Warmcore Tech が提供する、互いに独立した 2 種類の SDK 開発者向けプレビューをご案内します。それぞれ Python パッケージ、対象環境、ドキュメントが異なります。

## Xiaoling X3 SDK

**Xiaoling Robot** と **RDK X3 Head 2.0 V1.0.2** 向けです。配布パッケージは `warmcore-xiaoling-sdk`、Python のインポート名は `warmcore_xiaoling` です。[X3 概要](/jp/xiaoling-x3/v1/overview)からご確認ください。

## Xiaoling S100 SDK

RDK S100 と ROS 2 Humble を技術的な基準とする独立したプレビューです。配布パッケージは `xiaoling-s100-sdk`、インポート名は `xiaoling_s100` です。実機に搭載されたボードを個別に確認し、[S100 概要](/jp/xiaoling-s100/v1/overview)をご覧ください。

> **開発者向けプレビュー／ハードウェア未検証：** 両 SDK にはオフラインテストの記録がありますが、対象ロボットの実行環境とハードウェアの受け入れ検証は未完了です。

URL 内の `v1` はドキュメントの世代を示すもので、安定版 SDK 1.0 のリリースを意味しません。
