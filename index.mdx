Explore two independent SDK developer previews from Warmcore Tech. Each SDK has its own Python package, target environment and documentation.

## Xiaoling X3 SDK

For **Xiaoling Robot** and **RDK X3 Head 2.0 V1.0.2**. Distribution: `warmcore-xiaoling-sdk`; import: `warmcore_xiaoling`. Start with the [X3 overview](/en/xiaoling-x3/v1/overview).

## Xiaoling S100 SDK

An independent preview using the RDK S100 / ROS 2 Humble technical baseline. Distribution: `xiaoling-s100-sdk`; import: `xiaoling_s100`. Confirm the installed board for each unit. Start with the [S100 overview](/en/xiaoling-s100/v1/overview).

> **Developer Preview / Hardware Not Yet Verified:** Both previews have offline test evidence; target robot runtime and hardware acceptance remain unverified.

The `v1` path identifies a documentation generation, not a stable SDK 1.0 release.
