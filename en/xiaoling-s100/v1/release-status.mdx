> **Developer Preview / Hardware Not Yet Verified:** S100 ROS integration and physical behavior have not been verified on a target device. Local tests and profile labels do not establish hardware compatibility.

The merged private SDK reference is version `0.1.0a1`, a developer preview. It implements selected ROS, WebSocket and offline interfaces; availability is deployment-specific.

| Evidence | Status at the referenced SDK commit |
| --- | --- |
| SDK implementation | Selected interfaces implemented; manual head, eye and mouth motion disabled. |
| Offline testing | Unit and selected HTTP/WebSocket loopback tests recorded. |
| Target ROS runtime | Not tested on the S100 device baseline. |
| Hardware | Not verified; per-capability acceptance remains necessary. |

This is not a public distribution announcement. Confirm access, disclosure and redistribution terms with Warmcore Tech.
