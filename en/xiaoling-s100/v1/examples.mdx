## Normalize a synthetic facial-touch token

This example does not access ROS or a device:

```python
from xiaoling_s100 import Profile
from xiaoling_s100.events import FaceTouchAdapter

adapter = FaceTouchAdapter({"sample": "example"}, Profile.XIAOLING_ULTRA)
event = adapter.normalize("sample")
print(event.area, event.verified)
```

The mapping is an example, not a verified physical location. For the full fixture-based demonstration run `python examples/offline_touch.py` from the authorized SDK checkout.
