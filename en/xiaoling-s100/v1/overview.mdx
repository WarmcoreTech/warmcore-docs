> **Developer Preview / Hardware Not Yet Verified:** S100 ROS integration and physical behavior have not been verified on a target device. Local tests and profile labels do not establish hardware compatibility.

The Xiaoling S100 SDK is an independent ROS 2 and Python developer preview. Distribution `xiaoling-s100-sdk` version `0.1.0a1` uses the `xiaoling_s100` import. The technical reference is RDK S100 with ROS 2 Humble; confirm the installed board and software for each device. A Pro or Ultra product name does not establish its board model.

The preview implements selected dialog, audio, observation, touch, RF433, vision and text-model interfaces. Offline tests cover selected paths; target ROS and hardware acceptance remain pending. Manual head, eye and mouth motion is disabled. See [capability differences](/en/xiaoling-s100/v1/pro-ultra) and [release status](/en/xiaoling-s100/v1/release-status).
