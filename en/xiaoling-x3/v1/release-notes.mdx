> **Developer Preview / Hardware Not Yet Verified:** X3 hardware and the deployed robot runtime have not been validated. Local tests do not establish device compatibility, physical behavior, or safe operation.

## Developer preview documentation

This documentation describes a developer preview, not a production compatibility guarantee. The SDK has unit-test coverage for selected interfaces and local loopback coverage for WebSocket and text-provider paths. X3 hardware, deployed bridge behavior, and live provider compatibility remain unverified.

Physical head, eye, and mouth control and complete real-time voice replacement are not implemented. This page does not assert a public release date, package availability, or a specific SDK version. Confirm release and redistribution terms with Warmcore Tech.
