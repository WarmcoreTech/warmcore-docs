The X3 SDK requires an authorized checkout and a compatible Python environment. Hardware compatibility remains unverified.

## Requirements

For ROS features, use the Python version supported by the robot-compatible ROS installation and source that environment in the same shell. ROS dependencies come from that environment, not the SDK installer. Do not install on or modify the robot without operator approval.

## Installation details

Use the installation guide shipped with your authorized SDK checkout. Import checks verify local availability only, not compatibility with a physical X3 device. Experimental voice features require a version-matched, authorized vendor interface package. Do not replace the robot's interface package.

For optional WebSocket access, consult the matching SDK's `rosbridge` installation option. Follow your organization's approved package policy and use an operator-approved network.
