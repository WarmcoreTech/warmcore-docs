Warmcore Tech에서 제공하는 두 개의 독립적인 SDK 개발자 프리뷰를 소개합니다. 각 SDK는 Python 패키지, 대상 실행 환경 및 기술 문서가 서로 다릅니다.

## Xiaoling X3 SDK

**Xiaoling Robot** 및 **RDK X3 Head 2.0 V1.0.2**용입니다. 배포 패키지는 `warmcore-xiaoling-sdk`, Python 가져오기 이름은 `warmcore_xiaoling`입니다. [X3 개요](/ko/xiaoling-x3/v1/overview)에서 시작하세요.

## Xiaoling S100 SDK

RDK S100과 ROS 2 Humble을 기술 기준으로 사용하는 독립적인 프리뷰입니다. 배포 패키지는 `xiaoling-s100-sdk`, 가져오기 이름은 `xiaoling_s100`입니다. 각 장치에 실제로 설치된 보드를 확인하고 [S100 개요](/ko/xiaoling-s100/v1/overview)를 읽어 보세요.

> **개발자 프리뷰 / 하드웨어 미검증:** 두 SDK 모두 오프라인 테스트 기록이 있지만, 대상 로봇의 실행 환경과 하드웨어 승인 검증은 아직 완료되지 않았습니다.

URL의 `v1`은 문서 세대를 나타내며, 안정 버전 SDK 1.0 출시를 의미하지 않습니다.
