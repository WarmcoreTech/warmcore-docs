> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

## 시작하기 전에

사용이 허가된 SDK 체크아웃을 받고 버전을 확인하세요. 운영자가 승인한 워크스테이션과 격리된 네트워크를 준비해야 합니다. ROS 인터페이스 탐색 전에는 호환되는 ROS 환경, 도메인, 미들웨어 및 네임스페이스를 운영자에게 확인하세요. 로봇 소프트웨어를 변경하지 마세요.

## ROS 그래프 관찰

워크스테이션에서 로봇에 호환되는 ROS 환경을 로드하고 [설치 안내](/ko/xiaoling-x3/v1/installation)에 따라 SDK를 설치한 다음, 허가된 체크아웃에서 다음을 실행하세요.

```bash
python3 examples/x3_acceptance.py --ros --namespace robot --wait 5
```

`robot`을 운영자가 확인한 네임스페이스로 바꾸세요. 루트 네임스페이스를 사용하는 경우 `--namespace` 옵션을 생략합니다. 보고서는 발견된 인터페이스를 기록하지만, 탐색 결과만으로 메시지 전달이나 장치 안전성을 입증할 수 없습니다.

## 결과 해석

종료 코드 `0`은 선택한 관찰 항목이 기준을 충족했음을, `1`은 탐색이 불완전하거나 알려진 대화 경로가 일치하지 않음을, `2`는 입력·전송·설정 오류를 의미합니다. 민감정보를 제거한 보고서에 SDK 버전과 관찰 환경을 함께 기록하세요. [문제 해결](/ko/xiaoling-x3/v1/troubleshooting)을 참고하세요.
