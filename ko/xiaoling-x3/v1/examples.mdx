> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

## 읽기 전용 수락 검사

허가된 SDK 체크아웃에서 운영자가 확인한 네임스페이스를 사용합니다.

```bash
python3 examples/x3_acceptance.py --ros --namespace robot --wait 5
```

승인된 WebSocket 엔드포인트를 사용할 경우 선택적 클라이언트 의존성을 설치한 다음 실행합니다.

```bash
python examples/x3_acceptance.py --websocket ws://ROBOT_HOST:9090 --wait 30
```

`ROBOT_HOST`를 운영자가 제공한 엔드포인트로 바꾸세요. WebSocket 보고서는 관찰된 이벤트 수만 기록하고 텍스트 내용은 저장하지 않습니다. 로봇이 유휴 상태라면 관찰 시간 동안 이벤트가 없을 수 있습니다. 이벤트가 없다는 이유만으로 로봇 고장이라고 판단하지 마세요. 엔드포인트를 공용 인터넷에 노출하지 마세요.

## 워크스테이션 전용 텍스트 처리

텍스트 제공자 예제는 [오디오와 LLM 연동](/ko/xiaoling-x3/v1/audio-llm)을 확인하세요. 로컬 텍스트 응답은 로봇 연동 성공을 증명하지 않습니다.
