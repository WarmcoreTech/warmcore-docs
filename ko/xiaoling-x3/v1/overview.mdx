> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

Xiaoling X3 SDK `0.6.0a1`은 RDK X3 Head 2.0 V1.0.2를 대상으로 하는 Python 개발자 프리뷰입니다. ROS 2 인터페이스 탐색, rosbridge를 통한 대화 이벤트 관찰, 텍스트 연동 프로토타입 제작에 사용할 수 있습니다. 접근 권한과 재배포 조건은 Warmcore Tech와 합의해야 합니다.

## 테스트 완료 범위

ROS 대화 클라이언트와 노드 그래프 진단에는 단위 테스트가 포함되어 있습니다. 읽기 전용 WebSocket 이벤트 처리와 텍스트 모델 어댑터도 로컬 루프백 테스트를 거쳤습니다. 하지만 이러한 테스트만으로 실제 배포된 브리지, 운영 중인 모델 공급자 또는 X3 로봇이 검증된 것은 아닙니다.

## 기능 제한

프리뷰에는 머리, 눈, 입을 물리적으로 움직이는 명령이 구현되어 있지 않습니다. 실시간 음성 파이프라인 전체를 대체하는 기능도 구현되지 않았습니다. 버전을 평가하기 전에 [빠른 시작](/ko/xiaoling-x3/v1/quick-start)과 [릴리스 노트](/ko/xiaoling-x3/v1/release-notes)를 확인하세요.
