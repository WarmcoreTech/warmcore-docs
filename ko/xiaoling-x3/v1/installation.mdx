> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

## 요구 사항

Warmcore Tech에서 사용이 허가된 SDK 체크아웃과 배포 조건을 받으세요. 개발용 워크스테이션에서 Python 3.8 이상을 사용해야 합니다. ROS 기능은 로봇의 ROS 설치와 호환되는 Python 버전을 사용하고, 같은 셸에서 ROS 환경을 로드하세요. ROS 의존성은 SDK 설치 프로그램이 아닌 해당 환경에서 제공됩니다. 운영자 승인 없이 로봇에 소프트웨어를 설치하거나 수정하지 마세요.

## 체크아웃에서 설치

호환되는 `setuptools`와 `wheel`이 이미 설치되어 있는지 확인한 후 실행합니다.

```bash
python3 -m pip install --user --no-deps --no-build-isolation .
python3 -c "import warmcore_xiaoling; import warmcore_xiaoling.llm; print('SDK import OK')"
python3 -c "import rclpy; from std_msgs.msg import String; from std_srvs.srv import Trigger; print('ROS dialog imports OK')"
```

위 옵션은 의존성 설치와 빌드 격리를 비활성화합니다. 부족한 사전 요구 패키지는 별도로 준비해야 합니다. 가져오기에 성공해도 실제 X3 장치와의 호환성을 입증하지 않습니다. 실험적 음성 기능에는 권한이 있고 버전이 일치하는 벤더 인터페이스 패키지가 필요합니다. 로봇의 기존 인터페이스 패키지를 교체하거나 덮어쓰지 마세요.

선택 사항인 WebSocket 클라이언트는 SDK 체크아웃에서 `python -m pip install ".[rosbridge]"`로 설치할 수 있으며 추가 의존성을 다운로드할 수 있습니다. 조직의 승인된 패키지 정책을 따르고 [빠른 시작](/ko/xiaoling-x3/v1/quick-start)으로 이동하세요.
