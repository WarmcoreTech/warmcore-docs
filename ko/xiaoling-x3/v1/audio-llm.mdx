> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

## 텍스트 모델 연동

프리뷰 어댑터는 `LLM_CHAT_ENDPOINT`를 통해 호환되는 Chat Completions 엔드포인트를 지정하고 `LLM_MODEL`로 모델을 선택합니다. `LLM_API_KEY`는 필요한 경우에만 사용하세요. 비밀정보는 환경 변수나 승인된 비밀 관리 시스템에 보관하고 소스코드 또는 공유 로그에 작성하지 마세요. 루프백 이외의 연결에서는 키 전송에 HTTPS가 필요합니다. 일반 HTTP는 대화 내용도 노출하므로 루프백이나 명시적으로 승인된 보호 네트워크에서만 사용하세요.

허가된 SDK 체크아웃에서 다음 명령을 실행하면 워크스테이션에서 텍스트 응답을 요청할 수 있습니다.

```bash
python3 examples/llm_robot_reply.py "Hello"
```

호환되는 제공자를 미리 설정해야 합니다. 실제 운영 제공자와의 호환성은 검증되지 않았습니다. 결과를 로봇으로 보내면 재생에 영향을 줄 수 있으므로 별도의 운영자 승인이 필요합니다.

## 오디오 기능 범위

실험적인 PCM 유틸리티가 제공되지만 실제 재생에는 호환되며 승인된 인터페이스 패키지와 장치 검증이 필요합니다. 프리뷰는 마이크에서 모델까지의 전체 음성 파이프라인을 대체하지 않으며 립싱크도 보장하지 않습니다. 녹음 및 대화 내용을 보호하세요.
