> **개발자 프리뷰 / 하드웨어 미검증:** X3 하드웨어와 실제 로봇에 배포된 실행 환경은 아직 검증되지 않았습니다. 로컬 테스트만으로 장치 호환성, 물리적 동작 또는 안전한 운용을 보장할 수 없습니다.

## 실행 중인 그래프 조사

워크스테이션에서 로봇에 호환되는 ROS 환경을 사용해 실제 배포 상태를 확인합니다.

```bash
ros2 node list
ros2 topic list -t
ros2 service list -t
```

SDK 버전, 소프트웨어 버전, 네임스페이스 및 민감정보를 제거한 관찰 결과를 기록하세요. 사용 가능한 노드와 패키지는 배포된 이미지와 설정에 따라 다릅니다. 그래프에 노드가 보인다고 해서 정상 동작하거나 안전하게 제어할 수 있다는 뜻은 아닙니다.

SDK의 Python 가져오기 이름은 `warmcore_xiaoling`입니다. ROS 모듈은 호환되는 ROS 환경에서 제공됩니다. 벤더 인터페이스 정의는 별도로 관리하며 이 문서에서 재배포하지 않습니다. 필요한 인터페이스를 찾을 수 없으면 [문제 해결](/ko/xiaoling-x3/v1/troubleshooting)을 참고하세요.
