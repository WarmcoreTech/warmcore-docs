> **개발자 프리뷰 / 하드웨어 미검증:** S100의 ROS 통합 및 물리적 동작은 대상 장치에서 검증되지 않았습니다. 로컬 테스트나 프로필 이름만으로 하드웨어 호환성을 확인할 수 없습니다.

사용 가능한 인터페이스는 설치된 이미지, 실행 설정 및 연결된 주변 장치에 따라 달라집니다. 운영자에게 호환되는 ROS 환경을 확인하고 실제 그래프를 검사하세요.

```bash
ros2 node list
ros2 topic list -t
ros2 service list -t
```

SDK의 Python 가져오기 이름은 `xiaoling_s100`입니다. ROS 패키지와 벤더 메시지 타입 지원은 허가된 환경에서 제공합니다. 발견된 이름과 타입을 대상 설정과 비교하세요. 실행 파일, 패키지 또는 그래프 항목이 존재한다는 사실만으로 장치가 작동하거나 하드웨어가 활성화되었다고 판단할 수 없습니다.
