> **개발자 프리뷰 / 하드웨어 미검증:** S100의 ROS 통합 및 물리적 동작은 대상 장치에서 검증되지 않았습니다. 로컬 테스트나 프로필 이름만으로 하드웨어 호환성을 확인할 수 없습니다.

Python 3.10 이상과 사용이 허가된 SDK 체크아웃을 사용하세요. 체크아웃에서 기본 SDK를 설치합니다.

```bash
python -m pip install .
python -c "import xiaoling_s100; print('SDK import OK')"
```

가져오기 성공은 로컬 패키지가 설치되었음을 확인할 뿐입니다. ROS 연동에는 배포 환경과 호환되는 Python 인터프리터와 로드된 ROS 환경이 필요합니다. 일부 기능에는 승인된 버전 일치 벤더 메시지 타입 지원이 필요합니다. 정식 승인 경로로 확보해야 하며, 이 사이트에서는 배포하지 않습니다. 로봇의 Overlay를 덮어쓰지 마세요.

선택적인 WebSocket 클라이언트는 `python -m pip install ".[rosbridge]"`로 설치할 수 있으며 추가 의존성을 다운로드할 수 있습니다. 조직의 패키지 정책과 운영자가 승인한 네트워크를 사용하세요.
