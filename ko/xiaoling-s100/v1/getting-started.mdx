> **개발자 프리뷰 / 하드웨어 미검증:** S100의 ROS 통합 및 물리적 동작은 대상 장치에서 검증되지 않았습니다. 로컬 테스트나 프로필 이름만으로 하드웨어 호환성을 확인할 수 없습니다.

사용이 허가된 SDK 체크아웃과 해당 배포 조건을 확보하세요. Python 3.10 환경에서 [설치 안내](/ko/xiaoling-s100/v1/installation)를 따른 후, 체크아웃에서 오프라인 Fixture 예제를 실행합니다.

```bash
python examples/offline_touch.py
```

이 예제는 합성 이벤트만 처리하며 ROS, 네트워크 또는 장치 I/O에 접근하지 않습니다. 수신기나 얼굴 터치 하드웨어를 검증하지도 않습니다. 승인된 ROS 환경에서는 운영자가 확인한 그래프 검사를 수행할 수 있습니다.

```bash
python examples/monitor.py --namespace robot --inspect-only
```

`robot`을 배포 환경의 네임스페이스로 교체하거나 루트 네임스페이스에서는 옵션을 생략하세요. 탐색 결과는 특정 시점의 스냅샷이며 장치 동작의 증거가 아닙니다.
