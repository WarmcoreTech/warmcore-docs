> **개발자 프리뷰 / 하드웨어 미검증:** S100의 ROS 통합 및 물리적 동작은 대상 장치에서 검증되지 않았습니다. 로컬 테스트나 프로필 이름만으로 하드웨어 호환성을 확인할 수 없습니다.

병합된 비공개 SDK의 참조 버전은 `0.1.0a1`이며 개발자 프리뷰입니다. 일부 ROS, WebSocket 및 오프라인 인터페이스가 구현되어 있지만 실제 사용 가능 여부는 배포 환경에 따라 달라집니다.

| 검증 항목 | 참조 SDK 커밋의 상태 |
| --- | --- |
| SDK 구현 | 일부 인터페이스 구현됨. 머리·눈·입의 수동 움직임은 비활성화. |
| 오프라인 테스트 | 단위 테스트 및 일부 HTTP/WebSocket 루프백 테스트 기록. |
| 대상 ROS 실행 환경 | S100 장치 기준 환경에서 테스트하지 않음. |
| 하드웨어 | 미검증. 기능별 수락 검증이 필요함. |

이는 공개 배포 공지가 아닙니다. 접근 권한, 공개 범위 및 재배포 조건을 Warmcore Tech에 확인하세요.
