> **개발자 프리뷰 / 하드웨어 미검증:** S100의 ROS 통합 및 물리적 동작은 대상 장치에서 검증되지 않았습니다. 로컬 테스트나 프로필 이름만으로 하드웨어 호환성을 확인할 수 없습니다.

프리뷰는 그래프 탐색과 호환 인터페이스 사용을 지원합니다. 아래 상대 대화 이름은 선택한 배포 환경의 후보이며 네임스페이스와 리매핑에 따라 실제 이름이 달라집니다.

| 상대 이름 | 표준 ROS 타입 | SDK 작업 |
| --- | --- | --- |
| `dialog/text_input` | `std_msgs/msg/String` | 텍스트 게시 |
| `dialog/text_result` | `std_msgs/msg/String` | 구독 |
| `dialog/status` | `std_msgs/msg/String` | 구독 |
| `dialog/start_session` | `std_srvs/srv/Trigger` | 요청 |
| `dialog/stop_session` | `std_srvs/srv/Trigger` | 요청 |
| `touch/event` | `std_msgs/msg/Int32` | 구독 |

RF433과 PCM 경로에는 호환되며 승인된 벤더 메시지 타입 지원이 필요합니다. 이 사이트에서는 벤더 메시지 정의를 게시하지 않습니다. 엔드포인트가 일치해도 QoS 호환성이나 전달을 보장하지 않습니다. 텍스트 게시 및 서비스 호출은 장치에 영향을 줄 수 있으므로 운영자 승인이 필요합니다.
