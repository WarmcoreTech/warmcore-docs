> **开发者预览版／硬件尚未验证：** X3 硬件与已部署的机器人运行环境尚未完成验证。本机测试不能证明设备兼容性、实体行为或操作安全性。

## Python 无法导入 `rclpy`

在同一个 Shell 加载兼容的 ROS 环境，并确认 SDK 使用 ROS 对应的 Python 解译器。重新运行[安装说明](/cn/xiaoling-x3/v1/installation)中的导入检查。

## 找不到预期的接口

向操作人员确认核准网络、ROS Domain、Middleware、Namespace 及运行中的软件版本。使用 [Node 与 Package](/cn/xiaoling-x3/v1/nodes-packages) 的唯读指令检查节点和名称。探索本身无法证明消息送达或 QoS 兼容性。

## 没有收到 WebSocket 事件

确认已授权的端点、桥接服务可用性、访问政策及 Namespace。机器人闲置时，观察期间可能没有事件。避免将对话数据输出至共用日志。

## 寻求协助

通过既有的 Warmcore Tech 支持管道提供 SDK 与软件版本、运行操作、结束代码及去识别化错误消息。请移除凭证、地址、设备识别码、个人数据、对话文本及设置档内容。
