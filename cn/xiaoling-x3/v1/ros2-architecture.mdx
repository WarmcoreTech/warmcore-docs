## 集成方式

Python 应用程序可在兼容的 ROS 环境中使用 SDK 的 ROS 客户端，也可通过操作人员核准的 rosbridge 部署，使用唯读 WebSocket 客户端监听对话事件。这是不同的集成路径；WebSocket 观察功能不提供机器人指令访问权限。

## 探索与证据

ROS 名称可能受到 Namespace 或 Remapping 影响。SDK 诊断会检查观察到的名称、类型与部分 QoS 路由。节点图结果只是一次快照，不能证明端点身分、授权、持续健康状态、消息送达或实体行为。预览版接口规约详见 [Topic 与 Service](/cn/xiaoling-x3/v1/topics-services)。

## 网络边界

请使用操作人员管理的网络访问控制。客户端的 Topic 白名单只能限制该客户端，无法保护 rosbridge 服务器不受其他客户端访问。绝对不要直接将桥接服务暴露至公用互联网。不受信任的连接应使用操作人员管理、具备凭证验证与访问控制的 TLS 端点。
