## 文本模型集成

预览版适配器通过 `LLM_CHAT_ENDPOINT` 接受兼容的 Chat Completions 端点，并通过 `LLM_MODEL` 指定模型；只有必要时才设置 `LLM_API_KEY`。机密信息应存放于环境变量或核准的密钥管理系统，不要写入原代码或共用日志。除 Loopback 外，密钥必须经 HTTPS 传输。纯 HTTP 也会暴露对话文本，只能在 Loopback 或明确核准的受保护网络使用。

在已授权的 SDK 目录运行以下指令，可在工作站取得文本回应：

```bash
python3 examples/llm_robot_reply.py "Hello"
```

这需要设置兼容的模型提供者。在线提供者的兼容性仍未验证。将输出发送给机器人可能引发音频播放，须另取得操作人员核准。

## 音频功能范围

预览版提供实验性 PCM 工具，但播放功能需要兼容且获授权的接口套件，以及实际设备验证。预览版不会取代完整的麦克风至模型语音管线，也不保证嘴型同步。请妥善保护录音与对话内容。
