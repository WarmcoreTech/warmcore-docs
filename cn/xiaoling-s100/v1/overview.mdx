> **开发者预览版／硬件尚未验证：** S100 的 ROS 集成与物理行为尚未在目标设备验证。本机测试及产品配置文件标签不能证明硬件兼容性。

Xiaoling S100 SDK 是独立的 ROS 2 与 Python 开发者预览版。安装软件包 `xiaoling-s100-sdk` 的版本为 `0.1.0a1`，Python 导入名称为 `xiaoling_s100`。技术参考基准是 RDK S100 与 ROS 2 Humble；请逐台确认实际主板与软件。Pro 或 Ultra 的产品名称不能证明其主板型号。

预览版已实现部分对话、音频、观察、触摸、RF433、视觉与文本模型接口。离线测试涵盖部分路径，但目标 ROS 与硬件验收仍待完成。手动头部、眼球及嘴部动作已停用。详见[功能差异](/cn/xiaoling-s100/v1/pro-ultra)与[发布状态](/cn/xiaoling-s100/v1/release-status)。
