> **开发者预览版／硬件尚未验证：** S100 的 ROS 集成与物理行为尚未在目标设备验证。本机测试及产品配置文件标签不能证明硬件兼容性。

Warmcore 产品规格将视觉与追踪列为 Pro 功能；Ultra 包含这些功能，并增加脸部触摸。产品描述不能用来辨识主板，也不能证明特定机器的接口存在。

| 功能 | 产品规格 | SDK 预览版与证据 |
| --- | --- | --- |
| 视觉与追踪 | Pro 与 Ultra | 已实现图像与跟随状态订阅；实际相机与追踪功能仍需在目标硬件验证。 |
| 脸部触摸 | Ultra 添加 | 已实现离线范式；已检查的基准中，尚未确认即时事件路径。 |
| RF433 | 依个别设备而定 | 已实现接收器订阅；设备是否存在及代码对应仍需验证。 |

请与获授权的操作人员确认 SKU、主板、固件与周边设备。SDK Profile 只是标签，不代表硬件辨识结果。
