> **开发者预览版／硬件尚未验证：** S100 的 ROS 集成与物理行为尚未在目标设备验证。本机测试及产品配置文件标签不能证明硬件兼容性。

已合并的私人 SDK 参考版本为 `0.1.0a1`，属开发者预览版。它已实现部分 ROS、WebSocket 与离线接口；实际可用性取决于部署环境。

| 证据 | 参考 SDK 提交的状态 |
| --- | --- |
| SDK 实现 | 部分接口已实现；手动头部、眼球及嘴部动作停用。 |
| 离线测试 | 已记录单元测试及部分 HTTP／WebSocket 回环测试。 |
| 目标 ROS 运行环境 | 尚未在 S100 设备基准上测试。 |
| 硬件 | 尚未验证；各功能都需要个别验收。 |
