> **开发者预览版／硬件尚未验证：** S100 的 ROS 集成与实体行为尚未在目标设备验证。本机测试及产品设置档标签不能证明硬件兼容性。

接口是否可用取决于已安装的映像档、启动设置与连接的周边设备。请向操作人员取得兼容的 ROS 环境，并检查实际节点图：

```bash
ros2 node list
ros2 topic list -t
ros2 service list -t
```

SDK 的 Python 导入名称是 `xiaoling_s100`；ROS Package 与供应商类型支持由已授权环境提供。请将探索到的名称、类型与目标设置比较。可运行档、Package 或节点图项目本身，都不能证明设备正常运作或实体硬件已激活。
