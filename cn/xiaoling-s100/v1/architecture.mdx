> **开发者预览版／硬件尚未验证：** S100 的 ROS 集成与物理行为尚未在目标设备验证。本机测试及产品配置文件标签不能证明硬件兼容性。

调用者拥有的 ROS Node 为 `S100Client` 提供原生节点图；应用程序负责让 Node 持续 Spin 并关闭 SDK 资源。原生订阅及指令操作依赖实际激活的 ROS 环境与兼容端点。

独立的唯读 rosbridge 客户端可在核准的桥接服务部署后监听选定事件。WebSocket 回环测试不能证明实际机器人的桥接服务可用。客户端白名单无法保护服务器；对不受信任的连接，请使用操作人员管理的访问控制与加密。

文本模型适配器是工作站端的独立集成方案，不会替换机器人完整的即时语音管线。
