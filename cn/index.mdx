探索 Warmcore Tech 两套互相独立的 SDK 开发者预览版。每套 SDK 都有自己的 Python 软件包、目标运行环境及技术文档。

## Xiaoling X3 SDK

适用于 **Xiaoling Robot** 与 **RDK X3 Head 2.0 V1.0.2**。软件包名称：`warmcore-xiaoling-sdk`；导入名称：`warmcore_xiaoling`。从 [X3 总览](/cn/xiaoling-x3/v1/overview) 开始。

## Xiaoling S100 SDK

以 RDK S100 与 ROS 2 Humble 为技术参考基准的独立预览版。软件包名称：`xiaoling-s100-sdk`；导入名称：`xiaoling_s100`。请逐台确认实际主板，再阅读 [S100 总览](/cn/xiaoling-s100/v1/overview)。

> **开发者预览版／硬件尚未验证：** 两套 SDK 都具有离线测试证据，但目标机器人运行环境与硬件验收仍未完成。

网址中的 `v1` 代表文档版本代别，不表示 SDK 已推出稳定版 1.0。
